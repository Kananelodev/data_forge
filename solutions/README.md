# solutions/ — your anvil

Everything in here is yours to write. Each file is one quest. The functions
`raise NotImplementedError` until you implement them; the matching gate in
`gates/` tells you exactly what "correct" means.

Rule of the forge: **no copy-pasting answers.** Look things up, sure — but type
it yourself and be able to explain every line in your journal entry. The game
can check your tests; only you can check you understood.
